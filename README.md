# DANESH SPIN — Performance OS

A professional table tennis performance platform. Analytics, tactics, academy, ranking, and match intelligence — built with vanilla HTML, CSS, and JavaScript.

## Features

- **Dashboard** — KPI cards, live charts, goals, recent matches, upcoming drills
- **Analytics** — Radar profile, shot heatmap, win rate trends
- **Tactics Board** — Interactive court with shot plotting
- **Academy** — 9+ lessons with filters and modals
- **Blade Calculator** — Intelligent blade matching
- **Ranking** — Top players global ranking
- **Matches** — Log, view, and analyze matches
- **Training** — Drills + timer
- **Profile** — Athlete page with equipment and stats
- **Shop** — Products with cart
- **Community** — Social feed
- **Settings** — Appearance, account, notifications, data, about
- **Admin** — System overview

## Design System

- Dark-first with light theme support
- RTL support (Farsi)
- Custom Canvas charts (no dependencies)
- Command palette (⌘K / Ctrl+K)
- Toast notifications, modals, dropdowns
- Responsive from 320px to 4K

## Stack

- Pure HTML/CSS/JS — no build step, no dependencies
- Google Fonts: Geist, Instrument Serif, Geist Mono, Vazirmatn

## Deploy to GitHub Pages

1. Create a new repository on GitHub called `danesh-spin`
2. Upload all files (or push via git)
3. Go to **Settings → Pages**
4. Under **Source**, choose **Branch: main** and **Folder: / (root)**
5. Click **Save**
6. Your site will be live at `https://<your-username>.github.io/danesh-spin/`
